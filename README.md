# N-Puzzle Solver (A* Search Algorithm)

A Python implementation of the **N-Puzzle (15-puzzle, 8-puzzle)** game solver using the **A* Search Algorithm** optimized with **Manhattan Distance** heuristic.

## 📌 Features

- **A* Search Algorithm**: Finds the optimal (shortest) path to solve the puzzle.
- **Manhattan Distance**: Heuristic function for efficient state space evaluation.
- **Dynamic Board Size**: Works for any $K \times K$ puzzle size (e.g., $3 \times 3$, $4 \times 4$).
